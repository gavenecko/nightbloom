# Controller mapping

Open Options → Controller Mapping, or Controls & settings → Controller mapping. Select Player 1 or Player 2, choose an action, and press the desired physical button. The selected row says “Press a button…” while listening. Escape closes the dialog.

Assignments save immediately in this browser under nightbloom_controller_maps, separately for each player. If a button is already assigned, its action swaps to the previous button; assigning an optional unbound action may leave the other action unassigned. The screen shows the resulting assignments. Reset player defaults restores the current Classic/Arcade preset for that player.

Remappable actions: light, heavy, Special A, Special B, super, throw/throw escape, guard, an optional extra jump button, and pause/resume. Stick and D-pad movement remain fixed. Both players can pause a local match. Menu confirm/back remain Cross/A and Circle/B so combat remapping does not change menu navigation.

The pause move list displays the current player bindings and uses PlayStation names for detected Sony/DualSense controllers. Default Classic PS5 bindings are Cross light, Circle heavy, Square Special A, R2 Special B, Triangle super, L1 throw, R1 guard, Options pause. Jump is up on the stick/D-pad unless an extra button is assigned. Quarter-circle-forward plus heavy remains an alternative for Special B.

Special A and Special B identify distinct signature moves. A usually emphasizes close/mid-range pressure or a utility effect; B usually supplies a projectile/ranged attack. Examples: Vampira uses Blood Claw / Crimson Shot; Belladonna uses Fairy Dust / Nightshade Gale. Some fighters add armor, traps or other effects to these moves.

The remap dialog suspends gameplay, captures only fresh button presses, and gates buttons held while closing the dialog until they are released. Standard controller combat input is also enabled during the active Cursed Reliquary bonus; its ready/result screens retain normal confirm navigation.

Automated checks cover default/preset input, Sony labels, persistence, conflict swaps, invalid mappings, player isolation, direct Special B, extra jump, fixed D-pad behavior, held-button suppression, binding capture, local P2 pause and relic attacks. A physical-controller pass remains useful for each target browser/device.
